# file_manager — Dired-подобный файловый менеджер

Небольшой файловый менеджер для Windows в стиле Emacs **Dired**: каталог
показывается как текстовый буфер (одна строка = один файл), а управление
построено на Emacs-клавишах.

Построен на **Qt 6 Widgets (C++)** и собирается компилятором **Clang/LLVM**
(llvm-mingw) из поставки `D:\Qt`.

## Возможности

- Листинг в формате `ls -l`: строка метки, права, размер, дата, владелец, имя.
  Сверху всегда `.` и `..`; каталоги с `/`, симлинки с `-> target`.
- Подсветка («faces»): каталоги, симлинки, исполняемые файлы, метки, флаги удаления.
- Тёмная (чёрная) тема оформления.
- Emacs-минибуфер/эхо-область для сообщений, ввода и подтверждений `(y or n)`.
- Точка (point): строка под курсором подсвечивается на всю ширину (аналог `hl-line-mode`),
  плюс рисуется каретка (read-only `QPlainTextEdit` сам её не показывает).
- Метки файлов, флаги удаления, копирование, переименование, создание каталогов,
  обновление и сортировка листинга.
- Открытие файлов во внешнем редакторе.

## Сборка

Требуется Clang/LLVM, Qt 6, CMake и Ninja (всё лежит в `D:\Qt`).

```powershell
# из корня проекта
D:\Qt\Tools\CMake_64\bin\cmake.exe --preset debug
D:\Qt\Tools\CMake_64\bin\cmake.exe --build --preset debug
```

Либо обёрткой (собирает и, при желании, запускает):

```powershell
powershell -ExecutionPolicy Bypass -File tools\build.ps1 -Config debug -Run
```

Готовый бинарник: `build\debug\file_manager.exe`.

Пресеты `CMakePresets.json` (`debug`, `release`) уже привязывают компиляторы
`clang.exe`/`clang++.exe`, `CMAKE_PREFIX_PATH` на кит `6.12.0/llvm-mingw_64`,
Ninja и добавляют нужные каталоги в `PATH` (для `libc++.dll` при запуске).

### Запуск вручную

```powershell
$env:PATH = "D:\Qt\6.12.0\llvm-mingw_64\bin;D:\Qt\Tools\llvm-mingw2217_64\bin;$env:PATH"
build\debug\file_manager.exe [start-directory]
```

Или развернуть зависимости рядом с exe: `windeployqt.exe build\debug\file_manager.exe`.

## Внешний редактор

Файлы по `RET`/`f` открываются во внешнем редакторе. Команда определяется в порядке:

1. переменная окружения `EDITOR` (затем `VISUAL`);
2. настройка `editor/command` в QSettings (реестр: `dired-qt\file_manager`);
3. по умолчанию — `notepad.exe`.

В команде поддерживается плейсхолдер `%f` для пути к файлу, иначе путь
добавляется в конец. Примеры:

```
EDITOR = "code --wait %f"
EDITOR = notepad++.exe
```

## Клавиши

### Навигация
| Клавиша | Действие |
|---|---|
| `n`, `C-n`, `↓` | следующая строка |
| `p`, `C-p`, `↑` | предыдущая строка |
| `C-f`, `→` / `C-b`, `←` | символ вперёд / назад |
| `C-a`, `Home` / `C-e`, `End` | начало / конец строки |
| `M-<` / `M->` | начало / конец буфера |
| `C-v`, `PgDn` / `M-v`, `PgUp` | страница вниз / вверх |
| `C-l` | центрировать строку |

### Переходы и файлы
| Клавиша | Действие |
|---|---|
| `RET`, `f` | открыть файл (в редакторе) или войти в каталог |
| `^` | перейти в родительский каталог |
| `C-x C-f` | перейти в каталог по вводу |

### Метки
| Клавиша | Действие |
|---|---|
| `m` | пометить |
| `u` | снять метку |
| `DEL`, `C-d` | снять метку и перейти на строку вверх |
| `U` | снять все метки |
| `t` | инвертировать метки |

### Удаление
| Клавиша | Действие |
|---|---|
| `d` | пометить на удаление |
| `x` | выполнить удаление (с подтверждением) |
| `D` | удалить файл под курсором сразу |

Удаление безвозвратное (как в Dired). `.` и `..` удалять нельзя.

### Операции
| Клавиша | Действие |
|---|---|
| `C` | копировать |
| `R` | переименовать / переместить |
| `+` | создать каталог |
| `g` | обновить листинг (revert) |
| `s` | сменить порядок сортировки (name → size → time) |

Операции применяются к помеченным файлам, а если меток нет — к файлу под курсором.

### Прочее
| Клавиша | Действие |
|---|---|
| `?` | справка по клавишам |
| `q`, `C-x C-c` | выход |
| `C-g` | отмена (префикса / ввода) |

## Структура проекта

```
src/
  main.cpp
  app/MainWindow.{h,cpp}        окно, раскладка, привязка клавиш
  dired/DirEntry.h              структура записи каталога
  dired/DirModel.{h,cpp}        чтение каталога, сортировка, метки и флаги
  dired/DiredBuffer.{h,cpp}     текстовый вид листинга, точка (point)
  dired/DiredHighlighter.{h,cpp} подсветка (faces)
  dired/KeyMap.{h,cpp}          Emacs-подобный диспетчер клавиш
  dired/Commands.{h,cpp}        команды dired
  ui/Minibuffer.{h,cpp}         эхо-область / минибуфер
  ui/Theme.{h,cpp}              тёмная тема (палитра)
  util/FsOps.{h,cpp}            файловые операции
  util/Format.{h,cpp}           форматирование строк
```

## Тема

Приложение использует тёмную (чёрную) тему: стиль Fusion с тёмной палитрой
(`src/ui/Theme.cpp`), цвета подсветки подобраны под тёмный фон. Точка — строка
подсвечивается на всю ширину тёмно-синим (`40,52,70`), каретка светлая.

## Известные ограничения

- Листинг рендерится целиком: очень большие каталоги (сотни тысяч файлов) могут
  листаться с задержкой.
- Одно окно/буфер на каталог; история каталогов и вкладки не реализованы.
- `s` циклически переключает сортировку (без ввода произвольных ключей, как в Dired).
